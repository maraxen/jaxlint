## Reporting a vulnerability

Please report security issues privately to **67157875+maraxen@users.noreply.github.com**.

Include enough detail to reproduce or understand the impact (version, minimal repro if possible). Maintainer response time targets are best-effort for this alpha-stage project; critical fixes will be prioritized.
